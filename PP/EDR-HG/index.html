PANDUAN: INPUT HEATGUN

  1. Masukkan data berurutan: Assy No, CCT No, Tube No, W/P, dan Qty.
  2. Kolom Tube No otomatis tervalidasi dengan Masterdata. Layar kanan akan memunculkan Waktu Durasi Heatgun yang harus dipatuhi.
  3. Tekan ENTER setelah mengisi Qty. Kursor akan otomatis menghapus Qty lama dan siap untuk input Qty baru.
  4. Jika ingin mengganti WOS, gunakan tombol "Clear Semua Data" di atas.

PANDUAN: SINKRONISASI LISENSI

  1. Pastikan Anda telah membuat fail JSON pekerja.
  2. Kumpulkan seluruh fail JSON tersebut ke dalam 1 folder bernama data_users.
  3. Tahan klik (Drag) file / folder tersebut.
  4. Lepaskan (Drop) di dalam area bergaris putus-putus.
