PANDUAN: INPUT HEATGUN

  1. Masukkan data berurutan: Assy No, Tube No, Jml CCT, Joint DWG, W/P, dan Qty.
  2. Gunakan ikon ⚙️ di sebelah tombol Clear untuk mendaftarkan Assy Baru jika belum ada di database.
