PANDUAN: INPUT PRODUKSI (MP)

  1. Masukkan data menggunakan alat pemindai (Scanner) atau ketik manual berurutan mulai dari Assy No, CCT No, Part No, WP, dan Qty.
  2. Tekan tombol ENTER pada keyboard setelah mengisi Qty untuk merender data.
  3. Perhatikan peringatan Visual Part di sebelah kanan. Jika warna berkedip Merah/Kuning, AWAS material tersebut serupa dengan part lain!
  4. Klik tombol End Shift (warna kuning) hanya jika jam kerja Anda telah selesai untuk mengunduh laporan.
  5. Setelah End Shift ditekan, form input akan terkunci dan Anda masuk ke mode pengamat.

PANDUAN: SINKRONISASI LISENSI

  1. Pastikan Anda telah membuat fail JSON pekerja di menu Registrasi Lisensi.
  2. Kumpulkan seluruh fail JSON tersebut ke dalam 1 (satu) folder khusus di Desktop yang diberi nama persis: data_users.
  3. Tahan klik (Drag) file / folder tersebut menggunakan tetikus.
  4. Geser dan lepaskan (Drop) persis di dalam kotak bergaris putus-putus pada layar ini.
  5. Proses ini wajib dilakukan satu kali pada setiap perangkat/komputer baru di area produksi.
