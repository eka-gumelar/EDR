PANDUAN: INPUT PRODUKSI

  1. Mode dipilih saat awal login (Merah = Marker, Oranye = Heatgun).
  2. Di mode Marker: Isi huruf kabel pada kolom Marker (Kiri/Kanan). Gunakan tombol panah ⇛ untuk menduplikat. Qty akan dikali otomatis berdasarkan jumlah marker.
  3. Di mode Heatgun: Scan Assy, isi CCT No, WP, dan Qty. Perhatikan SOP yang tertera.
  4. Klik tombol End Shift (warna kuning) hanya jika jam kerja selesai untuk mengunduh laporan.

PANDUAN: SINKRONISASI LISENSI

  1. Pastikan Anda telah membuat fail JSON pekerja di menu Registrasi Lisensi.
  2. Kumpulkan seluruh fail JSON tersebut ke dalam 1 (satu) folder khusus di Desktop yang diberi nama persis: data_users.
  3. Tahan klik (Drag) file / folder tersebut menggunakan tetikus.
  4. Geser dan lepaskan (Drop) persis di dalam kotak bergaris putus-putus pada layar ini.
